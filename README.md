# Jarvis (native Android, fully on-device)
Gemma 4 runs on the phone via Google LiteRT-LM. No Termux, no server, no web page.
Push to GitHub -> Actions -> download artifact `jarvis-apk` -> install app-debug.apk
First run: open the gear icon -> download Gemma 4 E2B (needs a free Hugging Face read token + licence accepted at
huggingface.co/litert-community/gemma-4-E2B-it-litert-lm) or pick a .litertlm file.
